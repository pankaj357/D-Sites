# evaluation/data — curated datasets for the D-Sites revision

Every file here is script-generated and documented; these replace the undocumented/duplicated data used in v1 of the manuscript.

## Files

| File | Provenance / generation | Contents |
|---|---|---|
| `behera2020_FNR_DEPs_full153.csv` | Extracted from Behera et al. 2020 (Microb Pathog 140:103936, PMID 31862389) supplementary file `1-s2.0-S0882401019312185-mmc1.xlsx` (Sheets 2–3) | All **153** differentially expressed proteins: STM PM45 WT vs isogenic Δfnr, anaerobic LFQ LC-MS/MS. 59 down-in-mutant (FNR-activated), 94 up-in-mutant (FNR-repressed). Columns: accession, gene_symbol, log2FC, adj. p, direction. |
| `behera2020_FNR_DEPs_LT2mapped.csv` | Above mapped to the LT2 reference annotation (GCF_000006945.2 `genomic.gff`) via locus tag → gene name → curated synonym/product mapping | 137/153 DEP rows → **124 unique LT2 genes** (with contig/coords/strand + mapping method per row). |
| `behera2020_FNR_DEPs_absent_from_LT2.csv` | Remainder | 16 DEP rows with no LT2 protein-coding gene (other-strain locus tags, plasmid/phage proteins, pseudogenes e.g. hutU). |
| `regulondb_ecoli_FNR_sites.tsv` | RegulonDB Release 13.5 TF-RISet export (06-03-2025; Salgado et al. 2023, NAR gkad1072), rows with tfName=FNR → 159 unique TFRS → kept **97 Confirmed/Strong-confidence sites** with sequences. Coordinates verified on NC_000913.3 (core span + 10 bp flanks = RegulonDB tfrsSeq). `core_seq` column = strand-corrected binding-site core (14/15/22 bp) | **Replacement FNR positive set** — documented, citable, experimentally supported. Enables the reviewer-demanded cross-genome design: train on E. coli K-12 FNR sites → test/scan on S. Typhimurium LT2. |
| `ecoli_K12_MG1655_genomic.fna` / `.gff` | NCBI GCF_000005845.2 ASM584v2 (NC_000913.3), downloaded from NCBI FTP on 2026-10-08 | E. coli K-12 MG1655 reference genome + annotation for training the FNR model (cross-genome transfer experiment). |
| `collectf_clean.tsv` | `Original/data/known_sites/collectf_export.tsv` (CollecTF export, download date TBD by authors): 5,853 rows → full-row dedup 5,551 → drop computational-only-evidence rows → dedup by (TF, genome, start, end, strand) merging evidence → strand decoded to +/- | **5,336 unique experimentally-supported sites**, 154 TFs / 171 genomes. Benchmark positive sets: AmrZ@NC_002516.2 = **363**, GlxR@NC_009342.1 = **201** (fixes the unexplained 189 used before), CodY@NC_005945.1 = **260**, FNR@NC_000913.2 = **5** (E. coli K-12; zero Salmonella FNR sites exist in CollecTF). |
| `LT2_operons_heuristic_gap50.tsv` | Generated from `genomic.gff` protein-coding genes; same-contig, same-strand genes merged when intergenic gap ≤ 50 bp (standard distance-based operon heuristic; cite e.g. Salgado et al. 2000) | 2,750 operons covering 4,554 genes (876 multi-gene). For the operon-level FNR enrichment test (Reviewer 2, point iv). Optionally replace with DOOR2 predictions in the final revision. |

## Key numbers that change vs manuscript v8
- FNR "regulated genes": 69 → **124 unique LT2 genes** from the full 153-DEP set (selection now fully documented).
- GlxR known sites: 189 → **201**.
- CodY known sites: 339 raw rows → **260** unique sites (79 duplicate ChIP-Seq rows removed).
- CollecTF rows are no longer used raw; a single cleaned copy replaces the 4 duplicated exports.
